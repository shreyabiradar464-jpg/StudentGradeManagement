# Student Grade Management System

A simple console-based application developed using Core Java to manage student details and calculate academic results.

## Features

- Add student details, including name and roll number.
- Enter marks for five subjects.
- Calculate total marks and percentage automatically.
- Assign grades based on percentage.
- View all registered students.
- Search for students using their roll number.
- Validate marks between 0 and 100.
- Prevent duplicate roll numbers.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Classes and Objects
- Arrays and ArrayList
- Loops and Conditional Statements
- Methods and Constructors

## How to Run

1. Install the Java Development Kit (JDK).
2. Open the project folder in a terminal.
3. Compile the Java file:

   `javac StudentGradeManagement.java`

4. Run the program:

   `java StudentGradeManagement`

## How It Works

The application displays a menu that allows users to add students, view all student records, search by roll number, and exit the program. It calculates the total marks, percentage, and grade automatically.

## Grade Criteria

| Percentage | Grade |
|---|---|
| 90 and above | A |
| 75–89.99 | B |
| 60–74.99 | C |
| 35–59.99 | D |
| Below 35 | Fail |
